# Hash Gallery — هاش جاليري

تطبيق معرض صور وفيديوهات ذكي بينظّم مكتبتك بالهاشتاجات بدل الألبومات التقليدية.
كل حاجة شغّالة **محليًا بس على جهازك** — مفيش أي سيرفر أو رفع بيانات لأي مكان.

هذا المستند يشرح خطوة بخطوة إزاي تاخد المشروع من الـ ZIP ده لحد ما يبقى تطبيق
شغّال على موبايلك، من غير ما تحتاج تعرف برمجة.

---

## 1) المشروع ده مبني بإيه

- **Flutter** (Dart) — عشان يشتغل على أندرويد و iOS بكود واحد.
- **SQLite محلي** (`sqflite`) — بيخزّن الهاشتاجات وربطها بالصور بس، مش الصور نفسها.
- **بدون أي مكتبة سحابية** — مفيش Firebase ولا أي backend، الخصوصية 100%.
- **Codemagic** — هيبني نسخة APK (أندرويد) و IPA (iOS) تلقائيًا من على GitHub من
  غير ما تحتاج تنزّل Android Studio أو Xcode على جهازك.

كل المميزات اللي اتفقنا عليها في المواصفات متطبقة: التصنيف بالهاشتاج (فردي
وجماعي ولمسة طويلة سريعة)، البحث البسيط والمتقدم (AND/OR)، الهاشتاجات المخفية
بكلمة سر/بصمة، الإحصائيات، الوضع الفاتح/الداكن، العربي/الإنجليزي، الألوان
المخصصة لكل هاشتاج، التثبيت، الترتيب اليدوي بالسحب، وهكذا.

> **ملاحظة مهمة وصريحة:** الكود ده اتكتب بالكامل يدويًا بدون بيئة Flutter
> فعلية لتجربة البناء قبل التسليم (البيئة اللي بشتغل عليها معندهاش Flutter SDK
> ولا اتصال إنترنت لتحميله). يعني فيه احتمال ضعيف يطلع خطأ بسيط أول مرة تبني
> فيها المشروع على Codemagic. لو حصل كده، انسخ رسالة الخطأ من Codemagic
> وابعتهالي هنا وهساعدك تصلّحها فورًا — الأغلب هتبقى حاجة بسيطة زي رقم إصدار
> مكتبة.

## 2) رفع المشروع على GitHub

### الطريقة الأسهل: GitHub Desktop (من غير Terminal)

1. حمّل [GitHub Desktop](https://desktop.github.com) ونزّله وسجّل دخول بحساب GitHub بتاعك (لو معندكش حساب، اعمل واحد مجانًا على github.com).
2. فك ضغط ملف الـ ZIP اللي هبعتهولك في أي مكان على جهازك.
3. من GitHub Desktop: **File → Add Local Repository** واختار الفولدر اللي فككت فيه الملفات (`hash_gallery`).
4. هيقولك إنه مش Git repository، دوس **"create a repository"**.
5. اكتب اسم زي `hash-gallery` واضغط **Create Repository**.
6. دوس **Publish repository** فوق، وسيبه **Public** أو خليه **Private** حسب رغبتك، واضغط **Publish**.

خلاص المشروع بقى على GitHub بحسابك.

### الطريقة التانية: سطر الأوامر (Terminal / Command Prompt)

```bash
cd المسار/اللي/فيه/hash_gallery
git init
git add .
git commit -m "Initial commit - Hash Gallery"
git branch -M main
git remote add origin https://github.com/USERNAME/hash-gallery.git
git push -u origin main
```

(لازم تكون عامل الـ repo فاضي الأول من على github.com بزرار **New repository**).

## 3) ربط المشروع بـ Codemagic

1. روح على [codemagic.io](https://codemagic.io) وسجّل دخول بحساب GitHub بتاعك.
2. دوس **Add application** واختار الـ repo (`hash-gallery`) اللي رفعته.
3. Codemagic هيكتشف ملف `codemagic.yaml` الموجود جوه المشروع تلقائيًا ويقرا
   منه إعدادات البناء (الملف ده معمول مسبقًا بكل حاجة محتاجها).
4. هتلاقي Workflow اسمه **"Hash Gallery - Android"** — ده اللي هيشتغل من غير
   أي إعداد إضافي.

---

## 4) بناء نسخة أندرويد (الأسهل، تجربها دلوقتي)

1. من صفحة التطبيق في Codemagic، اختار **"Hash Gallery - Android"**.
2. دوس **Start new build**.
3. البناء هياخد حوالي 5-10 دقايق.
4. لما يخلص، هتلاقي رابط تحميل ملف **APK** في صفحة الـ Build نفسها (وكمان في
   إيميلك لو حطيت إيميلك في `codemagic.yaml` بدل `your-email@example.com`).
5. حمّل ملف الـ APK على موبايل الأندرويد بتاعك وثبّته (ممكن يطلب منك تسمح
   بـ"تثبيت من مصادر غير معروفة" من إعدادات الجهاز أول مرة).

كده التطبيق شغّال على موبايلك فعليًا وتقدر تجربه.

---

## 5) بناء نسخة iOS (محتاجة خطوة إضافية واحدة)

آبل بتطلب إثبات هوية المطوّر (Code Signing) قبل ما تسمح بتثبيت أي تطبيق على
آيفون، وده مش حاجة أقدر أعديها — لازم:

1. حساب **Apple Developer** (اشتراك سنوي 99$ من [developer.apple.com](https://developer.apple.com)).
2. من صفحة التطبيق في Codemagic → **Team settings → Code signing identities**،
   اربط حساب Apple Developer بتاعك (Codemagic عندها دليل مصوّر خطوة بخطوة
   لو احتجت: [docs.codemagic.io — iOS code signing](https://docs.codemagic.io/yaml-code-signing/signing-ios/)).
3. بعد الربط، شغّل Workflow **"Hash Gallery - iOS"** بنفس طريقة الأندرويد.
4. الناتج ملف **IPA** — تقدر توزّعه لنفسك/لفريق تجريبي عن طريق TestFlight.

لو مش محتاج iOS دلوقتي، ابدأ بالأندرويد وجرّب التطبيق، وارجع لخطوة iOS بعدين.

## 6) هيكل المشروع باختصار

```
lib/
  core/theme/       # الألوان والثيم (فاتح/داكن) بنفس الباليت اللي اخترتها
  data/             # قاعدة البيانات المحلية + الموديلات
  providers/        # إدارة الحالة (الصور، الهاشتاجات، الإعدادات)
  screens/          # كل شاشات التطبيق
  widgets/          # عناصر واجهة قابلة لإعادة الاستخدام
  l10n/             # نصوص العربي/الإنجليزي
android/  ios/       # مشاريع أندرويد و iOS الأصلية
codemagic.yaml       # إعدادات البناء التلقائي
```

## 7) لو عايز تغيّر حاجة بسيطة بنفسك

- **اسم التطبيق:** غيّره في `android/app/src/main/AndroidManifest.xml`
  (`android:label`) وفي `ios/Runner/Info.plist` (`CFBundleDisplayName`).
- **الألوان:** كله موجود في `lib/core/theme/app_colors.dart`.
- **النصوص العربي/الإنجليزي:** كله في ملف واحد `lib/l10n/app_strings.dart`.

أي تعديل تاني، تقدر تيجي تطلبه هنا وهعمله في الكود مباشرة.
